# 自助退货政策 v0.1

> 本文件仅用于虚构品牌 RIVET 的技术演示，不代表任何真实商家政策或法律意见。

## 1. 自助退货期限

普通线上商品在订单状态为 `DELIVERED` 后 7 个自然日内，可以申请自助退货。

## 2. 商品状态要求

商品应为未实际穿着使用，允许为 `NEW_UNWORN` 或 `OPENED_UNUSED`。已经使用、明显人为损坏的商品不进入自动退货流程，应转人工核验。

## 3. 排除项

标记为 `final sale` 的演示特价商品不支持自动退货。一个订单商品已经存在处理中退货或换货申请时，不得重复创建新申请。

## 4. 退款边界

创建退货申请不等于退款成功。v0 只创建 `RETURN_REQUESTED` 业务记录；收货验货和退款由后续系统处理。
