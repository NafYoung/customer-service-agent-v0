## 三、电商售后场景：政策剧变与自助化

1. **「仅退款」时代终结（2025-04 起）**：淘宝、京东、拼多多、抖音、快手等电商平台全面取消「仅退款」，改为「商家自主处理」售后，商家拿回自主权；媒体称「告别秒退」「仅退款落幕」，行业回归「反内卷」与良性竞争。**这是 2025 年电商售后最重要的政策变量**——平台不再替商家兜底，商家需要自己的售后决策能力（正是售后 Agent 的市场窗口）。
   - 来源：[北京商报：告别"秒退" 平台全面取消仅退款](https://www.bbtnews.com.cn/2025/0422/554521.shtml)｜[东方财富：全面取消仅退款 商家拿回自主权](https://finance.eastmoney.com/a/202504223384761778.html)｜[网经社：拼多多淘宝抖音快手京东全面取消](https://www.100ec.cn/detail--6648843.html)｜[新浪财经：仅退款落幕](https://finance.sina.com.cn/jjxw/2025-09-05/doc-infpkxsn6088995.shtml)

2. **平台用 AI 治理售后滥用**：淘宝天猫上线「售后 AI 假图识别模型」（2026-04），打击 P 图恶意骗退款；AI 客服开始「看凭证」（比对买家上传实物图与商品图、识别发票/物流单/缺陷图），「退换货会变快，但想靠一句话退款会更难」。
   - 来源：[DoNews：淘宝天猫上线AI假图识别模型](https://www.donews.com/news/detail/4/6526287.html)｜[新浪财经：售后AI假图识别模型上线](https://finance.sina.com.cn/tech/it/2026-04-23/doc-inhvntfe3772744.shtml)｜[今日头条：AI客服开始看凭证](https://m.toutiao.com/article/7637081465322357254/)｜[CSDN：凭证分类（ResNet-50识别发票/物流单/缺陷图）](https://blog.csdn.net/weixin_33660045/article/details/152498257)

## 五、人机协同与合规

1. **人机协同是行业共识**：「AI 客服只转人工不是好设计」，应通过工单协同让机器人承担更多闭环任务；分流策略（机器人先拦高频重复问题、人工接疑难）；客服中心岗位与管理方式随之重构。
   - 来源：[网易：工单协同让机器人闭环](https://b.163.com/cms/ai-ke-fu-wang-yi-qi-yu-2026-5Iw7ZekX.html)｜[合力亿捷：高频重复咨询如何分流](https://www.hollycrm.com/innews/9375.html)｜[合力亿捷：先分流还是全量接管](https://www.hollycrm.com/innews/10736.html)｜[合力亿捷：AI与人工共同服务后的管理变革](https://www.hollycrm.com/innews/10729.html)
   - 信息日期：2025-2026。

2. **生成式 AI 标识强制合规**：国家网信办等四部门 2025-03 印发《人工智能生成合成内容标识办法》（配套标准同步发布），对 AI 生成/合成内容提出显式与隐式标识要求；业内解读强调「技术标准+管理制度」并行。**对客服场景的含义：AI 生成的话术、AI 处理的售后结论应向用户可见标识。**

## 八、对 RIVET 项目的启示

> RIVET 定位：鞋服电商售后求职作品原型——单 Agent、6 个只读工具 + 3 个 prepare 工具、宿主确认后确定性执行、SQLite/FastAPI、holdout 评测体系、¥20 预算闸门。

### A. 增强作品说服力（对外叙事/README/面试话术）

1. **把「仅退款退潮」写进作品叙事**：2025-04 平台全面取消仅退款、改商家自主处理（[北京商报](https://www.bbtnews.com.cn/2025/0422/554521.shtml)），RIVET 的「宿主确认后确定性执行」正是对「商家拿回自主权但需自担风控责任」这一新局面的回应——比泛泛的「AI 客服」定位更有时代感。

2. **对标行业「独立解决率」指标**：行业头部案例 80%–91%（[腾讯云 30%→80%](https://cloud.tencent.cn/developer/article/2677630)、[阿里云 91%](https://developer.aliyun.com/article/1736543)）。在 README 里明确 RIVET 的 holdout 指标定义（如「预算内通过/拒绝准确率、转人工率、单均成本」），并诚实给出与行业数据的位置关系（局部场景可比或低于头部但架构可扩展），避免被质疑夸大。

3. **把 ¥20 预算闸门讲成「每单决策成本预算 + 风控闸门」**：对应行业反滥用（[淘宝假图识别](https://www.donews.com/news/detail/4/6526287.html)、[Riskified 反羊毛党](https://www.riskifiedchina.cn/resources/webinar/cx-teams-stop-fraud-abuse/)）与「成本账」叙事（[晓多：接管65%咨询量的成本账](https://www.xiaoduoai.com/blog/26129.html)）。展示「预算用尽 → 转人工」的日志，就是把预算闸门同时讲成成本控制与风控机制。

4. **工具分层对标「办事型 Agent」**：行业共识是 Agent 要「办事」而非「应答」（[AI 店小蜜：自主执行阶段](https://www.iheima.com/article-397284.html)；[Synerow：工具调用与工单闭环](https://developer.aliyun.com/article/1748573)）。RIVET 的「6 只读 + 3 prepare」天然对应「读-准备-确认-执行」分层，README 里要显式画出这张映射图。

5. **做一张「RIVET vs 店小蜜/京小智/企点」能力对照表**放进 README：明确 RIVET 是「单 Agent 最小闭环演示」（无多模态验货、无多租户、无真实平台对接），诚实定位反而增加可信度。

### B. 真正工程改进（代码/架构层面）

6. **增加「人工工单落库」接口**：哪怕只有 SQLite 表 + API 端点（如 `/escalate`），把「预算用尽/宿主拒绝 → 生成人工工单」闭环落地，直接对标行业「工单协同闭环」实践（[网易：工单协同](https://b.163.com/cms/ai-ke-fu-wang-yi-qi-yu-2026-5Iw7ZekX.html)），也让 holdout 评测可统计「转人工率」。

7. **决策留痕（审计日志）最小实现**：在 SQLite 中为每次决策记录：规则版本、模型置信度、工具调用序列、成本消耗、宿主确认状态。这是 PIPL 可解释性、AI 标识合规（[《人工智能生成合成内容标识办法》](https://www.spp.gov.cn//tt/202503/t20250314_690508.shtml)）与评测可追溯性的最小交集，工程量小、面试说服力大。

8. **评测升级为「预算约束下的成本-准确率曲线」**：holdout 集上同时报告「不同 ¥20 预算策略下的通过率/误判率/成本」，而不是单一准确率。这直接对标行业「成本账 + 独立解决率」双重叙事（[晓多案例](https://www.xiaoduoai.com/blog/26129.html)），且是 RIVET 最独特的卖点。

9. **预留多模态验货接口（可 mock）**：新增一个「凭证校验」工具签名（输入图片 URL/哈希，输出验货结论），内部可用规则或占位实现并标注 TODO，对标行业「图片验货/假图识别」方向（[AI假图识别](https://finance.sina.com.cn/tech/it/2026-04-23/doc-inhvntfe3772744.shtml)），展示架构前瞻性而不过度承诺。

10. **合规最小实现与声明**：代码/README 中体现（a）AI 生成内容标识（回复尾部「AI 助手生成」标注，对应标识办法）；（b）最小必要原则（只读取处理售后所需订单/物流字段，不存不必要个人信息，对应 PIPL）。这两点几乎零成本，但在求职作品中是差异化亮点。
